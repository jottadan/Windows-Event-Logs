# Objetivo
Compreender o seu uso.

---
Os principais tipos de logs pelo **Event Viewer** incluem System, Security, Application, Directory Service, DNS e Custom Logs. Cada evento possui informações como Level, Date/Time, Source, Event ID e Task Category.

Já o **wevtutil.exe** é uma ferramenta usada para consultar e gerenciar Event Logs pela linha de comando. Ela permite listar logs, consultar eventos, obter informações de configuração, exportar, arquivar e limpar logs, além de gerenciar publishers e manifests.

Para um SOC, a principal vantagem é poder automatizar consultas e análises de grandes volumes de eventos através de scripts, reduzindo a necessidade de analisar manualmente milhares de eventos no Event Viewer.
